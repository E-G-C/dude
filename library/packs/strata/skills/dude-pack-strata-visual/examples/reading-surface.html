Reading a stratified section

A long-form reading surface is not a documentation-site theme. It is any place a product asks someone to read for more than a few seconds: an article view, a changelog, a release note, an in-app help panel, a generated report, an onboarding walkthrough.

Prose is constrained to --strata-reading-measure (688px) while tables, figures, and code blocks are free to use the full width. That is the whole layout rule. Body text sits at 16/28, a deliberately looser measure than the 16/1.5 used for application chrome, because sustained reading and dense UI want different rhythms.

Layers are read by their edges

The section below is separated from this one by a rule, not by a shadow and not by a card. On a near-white ground the tonal difference between planes is around 1.15:1 — close to nothing — so the 1px rule is carrying the structure by itself. That is the trade the system makes deliberately: no depth effects, and an edge that always has to be there.

  • Flat planes, separated by hairline rules.
  • 4px radius on anything interactive, 8px at the very most.
  • Type-led hierarchy — size, weight, and rules, never boxes.
  • Monospace for metadata only, never as a display voice.

Note. Emphasis here comes from a 4px left rule in the semantic colour, over the standard inset plane. There is no tinted callout background, because a tint field is nearly invisible against the page on its own.

Table headers use the metadata treatment — monospace, letterspaced, uppercase, at the smallest size in the scale. That is what monospace is for in this system: marking data, not making a statement.

Careful. A vivid series slot is a fill. To write in a series colour on a light plane, use the matching -deep form — several vivid slots measure under 2:1 as text and are unreadable.

Code

The code surface is dark in both themes and shared by both palettes, so a snippet looks the same wherever it appears: 

@use "../tokens/strata.scss" as strata;

.panel {
  background: strata.strata-color("surface");
  // a plane is legible from its tone and its edge
  @include strata.strata-rule;
  border-radius: strata.$strata-radius-md;
}

Inline code such as --strata-reading-measure is marked by its font and a light background, with only a decorative hairline around it.

Tabs

Tab labels are metadata too. The selected tab is marked by a rule and a weight change — the same two devices the rest of the system uses.
