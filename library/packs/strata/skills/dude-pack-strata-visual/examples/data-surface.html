Data visualization

Seven categorical slots, ordered to maximise luminance separation between neighbours. The ramp is differentiated by hue, not by luminance — adjacent series reach only about 2:1 — so colour alone cannot carry the encoding. Every chart below also carries a direct label and a pattern.

Rules for series colour

  • More than two series requires a non-colour encoding: direct labels, distinct markers, dash patterns, or ordered position.
  • Use the slots in order — they are sequenced to maximise the luminance gap between neighbours.
  • Label with --strata-ink or --strata-muted, never with the series colour itself.
  • Stroke every mark with --strata-rule.
  • This is a categorical ramp. Never use it for sequential or diverging data — that needs monotonic luminance, which these seven deliberately do not have.

Values as text

A vivid slot is a fill. To write a value in a series colour on a light plane, use the matching -deep form: +12.4 mm uses --strata-series-4-deep, because the vivid slot behind it measures under 2:1 as text.
