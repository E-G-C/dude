Planned frames (080): documentation, not built in 073

Static, non-interactive full frames of where 080 documentation fits: P1 (Available rust), P2 (Installed clearline), and P4 (a SAMPLE project skill). It is not 073 product behavior, and no product state shows any of it. Frames use the real layout and pane widths (a 320px pane; a 164px overlay in a 180px window). Formatting is illustrative; rendering is decided in 080. Sample rows are labeled Sample. The Installed listing with project rows (formerly frame P3) and a project skill's ordinary details are now 073 product states: see Project agents and skills (SAMPLE) above. Frozen documents: library/packs/rust/pack.md and .github/skills/dude-pack-clearline-visual/README.md. Choose None, or Return to the product, to see the product as you left it.

  • Placement (a): pack documentation is one Documentation section in the pack details pane, after the facts and before the installed provenance (or projected-files note) and the files. It holds collapsed disclosures, like Recorded files: pack.md first, then one per member README in the pack's declared order. It sits at the same place in the 320px pane and in the narrow overlay. In the product states that position carries only the dashed Planned (080) note (Shown) or nothing at all (Hidden).
  • Placement (b): a project agent or skill's own documents go in the same Documentation section of its details, after the facts and before Files. Those details are a 073 product state now (a read-only note instead of actions, facts, Files with an agent's .support/ companions, the new-session caveat); frame P4 draws only the planned Documentation part of them.
  • Placement (c): 073 reserves the position and renders nothing there (FR-077). Documentation display itself stays in 080 unless the user answers Q6 otherwise.
  • Conventions: Figma Dev Mode annotations and Storybook's Outline toggle mark a reserved position without becoming a product control. VS Code Extensions and JetBrains Plugins keep the README or description in the details view and list VSIX and "Install Plugin from Disk" installs in the installed list; npm and NuGet pages use README sections; GitHub shows a folder's README. VS Code-style details tabs are deliberately not followed: they are sized for a full editor, not a 164 to 320px pane.
  • To confirm (recommended first): Q3 inline collapsed Documentation, or a documentation view opened from the same place. Q6 documentation display in 080 (recommended), or folded into 073. Q5 is answered: an import shows up in Installed right away.
